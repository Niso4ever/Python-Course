SECTION 2: PRODUCT — NEXUSRAG
================================================================================

NexusRAG is our flagship product. It allows enterprises to connect their internal
documentation, databases, and knowledge systems to large language models.

Key features (2026 edition):
- Multi-modal ingestion: PDF, Word, Excel, PowerPoint, HTML, video transcripts
- Hybrid search: vector similarity + BM25 keyword search combined
- Auto-chunking: intelligent document splitting that preserves context
- Citation tracking: every answer includes source document and page number
- Access control: RBAC — users only see documents they're authorized for
- Audit logs: all queries logged for compliance (SOC 2, GDPR)

Pricing:
- Starter: $2,000/month — up to 10GB documents, 5 users
- Professional: $8,000/month — up to 100GB, 50 users, SSO
- Enterprise: Custom pricing — unlimited storage, unlimited users, SLA

Supported LLM backends:
- Anthropic Claude (default — Sonnet 4.6 for queries, Haiku 4.5 for classification)
- OpenAI GPT-4o
- Self-hosted Llama 3.3 (on-premise option)

SECTION 3: PRODUCT — NEXUSAGENT
================================================================================

NexusAgent provides a framework for deploying autonomous AI agents in enterprise
environments. Unlike simple chatbots, NexusAgent instances can:

- Browse the web and retrieve current information
- Execute Python code in a sandboxed environment
- Query internal databases via SQL
- Send emails and Slack messages (with approval workflows)
- Create, edit, and organize files in cloud storage
- Make API calls to external services

In 2026, the average NexusAgent deployment completes 340 autonomous tasks per
day per agent instance, with a human approval rate of less than 12% (meaning
88% of tasks complete without human intervention).

Agent templates available:
- Research Analyst: web research, report writing, competitive intelligence
- Data Analyst: SQL queries, chart generation, insight extraction
- Customer Support: ticket triage, resolution drafting, escalation routing
- Content Creator: research, drafting, SEO optimization, scheduling
- Code Reviewer: PR analysis, bug detection, documentation generation
