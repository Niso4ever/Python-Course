```python

```
The incorrect way of writing a dictionary is shown here, emphasizing it will cause an error, as if a paper is filled out wrong.

```python

```
This notes that the following line is the correct way to write a dictionary.

```python

```
This shows how to properly create a dictionary, similar to correctly filling out an application form.

```python
# ❌ MISTAKE 2: Forgetting quotes around keys
```
This warns about another common error, like forgetting to underline important words in a note.

```python

```
It incorrectly shows a key without quotes, highlighting it will lead to confusion, just as forgetting to label a box can lead to chaos.

```python
# ✅ CORRECT:
```
Another stop indicating correct syntax.

```python
correct_dict = {"model": "claude"}
```
It correctly shows the right way to define a key in a dictionary.

```python
# ❌ MISTAKE 3: Accessing keys that don't exist
```
This highlights an error when trying to access information that isn’t there, like trying to open a door that’s locked.

```python
metadata = {"score": 0.95}

# value = metadata["confidence"]  # KeyError: 'confidence'
```
Trying to retrieve a non-existing key would lead to an error, just like being told you can't enter a room.

```python
# ✅ CORRECT: Check if key exists first
```
This indicates the correct approach before accessing keys.

```python
if "confidence" in metadata:
```
This checks if that key exists first.

```python
    value = metadata["confidence"]
else:
    value = None  # Default value
```
If it is there, it retrieves the value; if not, it sets the value to None, like checking for guests before making dinner.

```python
# OR use .get() with default
```
Here, it suggests another method to safely get a value.

```python
value = metadata.get("confidence", 0.0)  # Returns 0.0 if key missing
```
This method tries to get the value and gives 0.0 if it’s not found, like keeping a spare key handy.

```python
# ❌ MISTAKE 4: Not handling None values
```
This warns that not checking for None values can cause problems, like trying to cook without any food.

```python

# if metadata["score"] > 0.80:  # TypeError: '>' not supported for None
```
This example shows that trying to compare None to a number would cause an error, akin to trying to grade homework that's blank.

```python
# ✅ CORRECT: Check for None
```
It indicates that you should check for None values before using them.

```python
if metadata["score"] is not None and metadata["score"] > 0.80:
```
Here, it confirms there is a value before comparing it, like ensuring there's food before cooking.

```python
    print("High score")
```
If there's a valid score above 0.80, it congratulates the high score, much like praising a student for good grades.
